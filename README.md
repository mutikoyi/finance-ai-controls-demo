# Finance AI Controls Demo

A small AI-assisted finance controls prototype using entirely fictional data.

## Purpose

This prototype demonstrates how practical accounting requirements can be translated into a working finance workflow with AI assistance.

The finance requirements and acceptance criteria were defined from the perspective of an experienced finance practitioner. AI was used to help structure and implement the browser-based prototype.

This is **not production accounting software**. It is a demonstration of finance logic, control design, testing and iterative product thinking.

## What the prototype demonstrates

- Double-entry journal validation
- Prevention of unbalanced journal posting
- Account-code validation
- Period-lock control
- General ledger generated from posted journals
- Trial balance generated from the ledger
- Accrual and prepayment examples
- Reversal journal example
- Immutable-style audit trail for posted journals
- Clear control checks before posting

## Product-development method

**finance requirement -> control rule -> prototype -> test scenario -> review -> refinement**

All sample data is fictional.
